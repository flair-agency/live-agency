# LIVEセッション同一性の変更

2026-09-08、所有者は「同じセッション候補として扱い、終了時刻の差は競合で停止する」を選択した。この判断を現行のLIVE記録Skillへ実装する。

変更カード：主分類B、副分類D。境界はLIVE Skillの観測・計画契約。creatorと正規化した開始時刻を照合キーとし、終了差は競合停止。未知の宛先・likes競合・承認hash/count・結果不明時の読戻し・指標記録の条件を維持する。今回の完了条件は観測重複、既存履歴差異、既存開始重複、同値タイムゾーン、旧計画の再確認を直接テストし、文書と配布資源を合わせること。実履歴の統合・削除・更新や本番切替は選択しない。次ゲートは正式名・配布版および指定インストールの受入。並列なし。前版のソース・旧計画を保持し、今回の所有差分のみ戻せる。

同じcreatorの開始時刻を同じ瞬間へ正規化して比較する。終了時刻は保持する観測値で、違う終了を自動的に上書きしない。既存の異なる終了を持つ同時開始行を勝手に選ばない。新しい計画には同一性規則の識別子を含め、旧計画は読取りを維持しながらapply時の再計画hash照合で再承認を必要にする。
